# urban-observatory

AI-assisted public-data structure for housing and urban intervention intelligence.

`urban-observatory` is an open-source prototype for structuring fragmented public planning, housing, environmental, and budget information into intervention-oriented evidence briefs. The project focuses on constraints, tradeoffs, sequencing, evidence quality, and likely consequences rather than predictive certainty.

## Sources of Truth

- **Repo** = project state (artifacts, decisions, current navigation)
- **[`AGENTS.md`](AGENTS.md)** = workflow rules, agent-agnostic
- **External grounding note** = intent, audience, philosophy, foundational premises, durable loose threads
- **[`docs/architecture.md`](docs/architecture.md)** = repo-local architecture and source-of-truth boundaries

## Status

`urban-observatory` is in initial bootstrap. The repo currently carries the workflow-and-architecture starter inherited from `apexSolarKiss/control-surface`. Project-specific artifacts (data model, intervention-brief model, case studies, examples) follow as the work proceeds.
